##  Hermes Agent 是什么

一句话：  ** 一个会自我进化的开源AI智能体框架  ** ，由 Nous Research 开发。

** 🧠 自进化学习  **

每次任务完成后自动提取经验，生成可复用的 Skill 技能包。用得越多，它越强。

** 💾 四层持久记忆  **

工作记忆、情景记忆、语义记忆、程序记忆——像人脑一样组织和检索信息，跨会话不遗忘。

** 🔌 20+ 模型任意切  **

OpenAI、Claude、Gemini、DeepSeek、千问、GLM、Kimi……零锁定，一条命令换模型。

它和其他Agent最本质的区别是：  ** 其他Agent是工具，Hermes是一个不断成长的"心智"。  **

小米已经把 MiMo-V2-Pro 接入了Hermes Agent框架。

02

##  核心架构：四层内存 + 自进化循环

灵感来自认知科学的人类记忆模型。四个层级各司其职：

LAYER 1 · Working Memory

工作记忆

当前会话上下文，速度最快，任务结束即释放

LAYER 2 · Episodic Memory

情景记忆

历史会话的摘要，按时间索引，支持回溯

LAYER 3 · Semantic Memory

语义记忆

向量化知识库，存储事实、概念和项目知识

LAYER 4 · Procedural Memory

程序记忆

自动生成的 Skill 技能包，可复用的工作流模板

** 自进化学习循环  ** 是这套系统的灵魂：

任务执行  →  结果评估  →  经验提取  →  Skill 生成  →  下次复用

↻ 成功的工作流自动抽象为可复用技能

##  安装教程：从零到运行

1  ** 一键安装  **

# Linux / macOS / WSL2 / Termux

curl  -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh |  bash 

# 重新加载 shell

source  ~/.bashrc

Windows 用户先装 WSL2，再执行以上命令。

2  ** 配置模型  **

hermes  model  # 交互式选择提供商和模型

hermes  setup  # 或一次性完成所有配置

3  ** 开始对话  **

hermes  # 就这么简单，开聊！

4  ** 安全沙箱（强烈推荐）  **

# Docker 隔离，防止误操作主系统

hermes  config set terminal.backend docker

##  六大进阶功能

💬 消息平台集成

Telegram、Discord、Slack、WhatsApp、Signal、Email、Home Assistant —— 7大平台全覆盖。

hermes  gateway setup

🎙️ 语音模式

CLI 中 Ctrl+B 录音，Telegram/Discord 语音频道直接对话。支持本地 Whisper。

pip  install  "hermes-agent[voice]"

# 聊天中输入 /voice on

🧩 技能市场

搜索社区 Skill 直接安装，或让 Agent 从你的工作中自动学习生成。

hermes  skills search kubernetes

hermes  skills install openai/skills/k8s

⏰ 定时自动任务

用自然语言描述，Agent 自己建 cron，通过消息网关推送结果。

"每天早上9点，检查 Hacker News 的 AI 新闻，发 Telegram 摘要给我"

🔌 MCP 协议 + 编辑器 ACP

原生 MCP 接入外部工具（GitHub/数据库等）；ACP 协议无缝嵌入 VS Code / Zed / JetBrains。

hermes  acp  # 启动编辑器后端
