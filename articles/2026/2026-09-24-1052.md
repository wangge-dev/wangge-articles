点击  在此电脑使用WebCodex

之后选择文件夹

![](https://mmbiz.qpic.cn/mmbiz_png/H159gTor6F5xZ4Bbic3U6d5Hica8djhfU9yArBKWt6nr3Fkf0qv6uHKW1KMhGLuD8Kq9Xh23iaWLia75Vb3kNL7qORYUWGU0tiaqibAYjfAtgKdqs/640?wx_fmt=png&from=appmsg)

随便新建一个文件夹都行，比如

E:\网页版

先用测试目录，不要直接授权整个硬盘。建好之后选择文件夹路径即可

回首页展开「查看运行诊断」  ，确认  ` Service  ` 、  ` Runner  ` 、  ` Project  `
都准备好了，路径也正确。状态不对先处理这一步，不急着往后填连接。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/H159gTor6F5icUgVfQSkCM7E0UCMsrpVydicO1tjibBfUiaDXntzyo97K8xshbUEPMXdC8r6xvIFibHlWWh9CQLibZkJ4ppjibqZLGz3u4KSaG7DP8/640?wx_fmt=png&from=appmsg)

展开「查看运行诊断」，检查本机服务、Runner 与项目的状态。

第三步：给这台电脑建一条专用连接

浏览器打开：

https://platform.openai.com/settings/organization/tunnels

登录自己的账号，点击右上角  Create tunnel  。名称随便写：

![平台：创建隧道的入口](https://mmbiz.qpic.cn/sz_mmbiz_png/H159gTor6F7fu5WVmIRNDL5BjUY55QdeXAu0b6MrVTrPxojtfk2FRGiaoRwyG3JBr5ZY5ZtYyGWiaYahnlicBzmpiajxAW68JZfCgcxhDrnoicfo/640?wx_fmt=png&from=appmsg)

在平台的 Tunnels 页面，点击右上角「Create tunnel」。

WebCodex-MyPC

` Tunnel  ` 先理解成连接通道。下面两个字段分别设置：

Organizations：选这条连接所属的平台组织，个人账号选自己的个人组织。

ChatGPT workspaces：选准备使用它的 ChatGPT 工作区

![平台：填写新连接名称](https://mmbiz.qpic.cn/sz_mmbiz_png/H159gTor6F62iasaPaGoVy13vicqrBLMG1r8OErYK0pFRm4a3EpUqo4VWuygljmBq7CHc3W9D6tjMicyiajfgt4QTg3ULWzqlrrztceiaia0yeQVQ/640?wx_fmt=png&from=appmsg)

填写新连接名称。此图还没选 ChatGPT workspaces，接着看下一张。

![平台：勾选ChatGPT工作区](https://mmbiz.qpic.cn/mmbiz_png/H159gTor6F73VFq8HlP3TTtpPVFia8LicvkaV2t6XVDPicheft5UkyCJL6rekwWzkryVbzvflYN7nmTqqqvPAEtMfCEgJfbpKknw1kbos1l9HU/640?wx_fmt=png&from=appmsg)

选中自己的 ChatGPT 工作区，确认出现勾选和标签后，再保存。

保存后，复制平台生成的、以  ` tunnel_  ` 开头的完整编号，后面填回电脑。

![](https://mmbiz.qpic.cn/mmbiz_png/H159gTor6F7eMeuJEXUWDkccib4ricR0ufVtsuBQsjjjNt45R3aPTuAkekEAGaLYnOWXHkVIx6CP0XmbArLXz12lRgT8Q9bLC9nzFnKc6oeHM/640?wx_fmt=png&from=appmsg)

名称是给自己辨认的，编号才是后面连接时要用的。复制时认准新建的这一行，不把旧连接的编号和新名称混在一起。

第四步：准备连接用的 API key

编号与密钥是两样东西：  前者指定连接，后者用于验证使用权限。

首先打开：

https://platform.openai.com/settings/organization/api-keys

确认组织与刚才一致，点击  Create new secret key  ，名称随便写

![](https://mmbiz.qpic.cn/mmbiz_png/H159gTor6F5kyjBez5xfZJnMaDRICcPYKW1ddjOhibDtvZN18Y0F4icZr6738T2zeEAOrUaz15fl6m8Vp6Mialb2QFp0fpiaPxE8WTyzeZUwZ48/640?wx_fmt=png&from=appmsg)

优先用  Restricted  ，按文档配置必要的  ` Tunnels: Read  ` 和  ` Tunnels: Use  ` 。  

创建后妥善保存，完整密钥通常只显示这一次。  只填进本机 WebCodex，不发聊天、不放进截图。也可以把  密钥复制保存下来，以防忘记了。  

API key 是连接凭据，  不等于把任务改成模型 API 计费  。  

第五步：填回 WebCodex，保存，再启动

回到电脑上的 WebCodex，进入「连接」→「检查 ChatGPT 安全隧道配置」或对应配置区域。

Tunnel ID 填连接编号，Tunnel API key 填密钥。

点击「保存配置」  ，再点  「启动安全隧道」。别误点旁边的清除配置。

![Desktop：编号和密钥的填写位置](https://mmbiz.qpic.cn/sz_mmbiz_png/H159gTor6F72geFxIOEa8MBlEAzRnFfohMFjVicbZc9v3G0kDNbVDrib8GMym87hC2hTOyngh8PV9bYN5xkkoMDxR83knftNQmq6xgbg0duCc/640?wx_fmt=png&from=appmsg)

保存后密钥框清空，不一定是没保存；已保存时会提示「留空保留密钥」  

等它显示：

OpenAI Secure Tunnel 已就绪，等待 ChatGPT 连接

电脑这边准备好了。「等待 ChatGPT」不是让你重新创建连接，下一步去 ChatGPT 添加即可。

![新连接：隧道已就绪](https://mmbiz.qpic.cn/mmbiz_png/H159gTor6F7P5CmXBUQD4XmClQaFTr6lP6IT901CmgB6ugSqxlCGyomjp7fzwDtWtt3tB9wCFt0NyreLREoCKmUXP01arO9GXjmibvZwxmWk/640?wx_fmt=png&from=appmsg)

电脑端新连接已就绪。接下来到 ChatGPT 添加它，再做实际读写检查。
